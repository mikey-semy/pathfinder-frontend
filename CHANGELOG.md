# История изменений PathFinder

## [v0.4.0] - 2026-02-12

### Добавлено ✨

#### PWA поддержка
- Манифест приложения (`public/manifest.json`)
- Иконки для PWA (favicon, apple-touch-icon, android-chrome)

### Изменено 🔄

#### Единицы измерения
- σв (предел прочности) теперь отображается в **Н/мм²** вместо кгс/мм²
- Автоматическая конвертация между формой (Н/мм²) и расчётным движком (кгс/мм²)
- Обновлены значения по умолчанию: 130-133 кгс/мм² → 1275-1305 Н/мм²

#### Формула ВСР (по требованию заказчика)
- Изменён коэффициент приращения прочности с **0.6 на 0.4**
- Формула: `0.4 × (C + d₀/40 + ε) × Σε`
- Подробности в `docs/FORMULA_VERIFICATION.md`

#### Идентификаторы марок стали
- Упрощены с `k85` до `85` (только числовые)

### Рефакторинг 🔨

#### Миграция на FSD структуру
- Всё перенесено в `src/` директорию
- `app/` → `src/app/`
- `components/ui/` → `src/shared/ui/`
- `lib/` → `src/shared/lib/`
- `ThemeProvider` → `src/app/providers/`
- `ThemeToggle` → `src/features/theme-toggle/`
- `HelpModal` → `src/features/help-modal/`

#### Очистка проекта
- Удалены пустые папки-заготовки (widgets, entities/steel-grade, app/providers, etc.)
- Удалены все feature-ветки, код слит в master

### Структура проекта
```
src/
├── app/              # Next.js App Router + providers
├── entities/         # Бизнес-сущности (calculation)
├── features/         # Фичи (form, export, theme-toggle, help-modal, etc.)
└── shared/           # Переиспользуемое (ui, store, lib)
```

## [v0.3.0] - 2026-01-30

### Добавлено ✨

#### Справочник марок стали
- Встроенный справочник из 6 марок высокоуглеродистых сталей (К70, К75, К80, К85, 65Г, 70Г)
- Автоматическое заполнение параметров материала при выборе марки
- Возможность ввода пользовательских параметров для других марок
- Select компонент с описанием каждой марки

#### Переключение тем
- Поддержка светлой и темной темы
- Кнопка переключения в правом верхнем углу
- Сохранение выбранной темы в localStorage
- Адаптивные цвета для всех компонентов

#### Экспорт результатов
- Экспорт в Excel (формат .xlsx)
- 4 листа: входные параметры, базовые расчеты, по блокам, итоговые
- Кнопка экспорта над результатами
- Автоматическое имя файла с датой расчета

### Улучшено 🔧

#### Мобильная адаптация
- Адаптивные отступы и размеры шрифтов (sm:, lg: breakpoints)
- Прокручиваемые таблицы на мобильных устройствах
- Оптимизированная форма для маленьких экранов
- Адаптивная сетка для карточек результатов

#### UI/UX
- Улучшена структура страницы с заголовком результатов
- Добавлены метаданные страницы (title, description)
- Плавные переходы между темами
- Иконки для кнопок действий

### Исправлено 🐛

#### Критические ошибки
- **Исправлена ошибка**: "Cannot read properties of undefined (reading 'toFixed')"
  - Проблема: пропущенные блоки (isOmitted: true) не имели полей для отображения
  - Решение: фильтрация только активных блоков во всех компонентах
  - Затронутые файлы:
    - `ResultsTable.tsx`
    - `ResultsCharts.tsx`
    - `exportToExcel.ts`

### Технические изменения 🔨

#### Новые зависимости
- `next-themes` - управление темами
- CSS переменные для темизации

#### Новые файлы
- `src/entities/calculation/model/steelGrades.ts` - справочник марок стали
- `src/shared/ui/ThemeProvider.tsx` - провайдер тем
