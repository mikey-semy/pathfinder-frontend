## Исправленные формулы

### 1. Среднее обжатие (L4)

**Было (неправильно):**
```typescript
const exponent = 2 / totalTransitions;
const reduction = 1 - Math.pow(Math.pow(finalSize / initialSize, 2), exponent);
```

**Стало (правильно):**
```typescript
const exponent = 1 / totalTransitions;
const reduction = 1 - Math.pow(Math.pow(finalSize / initialSize, 2), exponent);
```

**Формула из Excel:** `1 - ((FINSIZE/INSIZE)^2)^(1/NoDIES)`

### 2. Единичное обжатие для блока (строка 18)

**Было (неправильно):**
```typescript
const taper = (distributionCoeff * (averageBlockNumber - blockNumber)) / 100;
const reduction = averageReduction + taper;  // averageReduction в процентах!
```

**Стало (правильно):**
```typescript
const averageReductionDecimal = averageReduction / 100;  // Конвертируем в доли
const taper = (distributionCoeff * (averageBlockNumber - blockNumber)) / 100;
const reductionDecimal = averageReductionDecimal + taper;
return (reductionDecimal * 100);  // Возвращаем в процентах
```

**Формула из Excel:** `AVREDN + (TAPER * (L2 - blockNumber) / 100)`

## История изменений формулы ВСР (Временное Сопротивление Разрыву)

### Проблема

Оригинальная формула из Excel давала завышенные значения σв (ВСР) порядка 2000+ кгс/мм², что не соответствовало ожиданиям заказчика.

### Исследованные варианты

Были созданы три ветки с разными вариантами формулы расчёта приращения прочности:

| Ветка | Формула | Описание |
|-------|---------|----------|
| `formula-v1-excel` | `0.6 × (C + d₀/40 + ε) × Σε` | Оригинал из Excel, высокие значения ВСР (~2000+) |
| `formula-v2-theory` | `0.6 × (C + d₀/40) × Σε` | Без единичного обжатия (ε), значительно ниже |
| `formula-v3-coeff` | `0.4 × (C + d₀/40 + ε) × Σε` | Коэффициент 0.4 вместо 0.6, на ~33% ниже |

Где:
- `C` — содержание углерода
- `d₀` — начальный диаметр заготовки
- `ε` — единичное обжатие
- `Σε` — суммарная деформация (STRAIN)

### Принятое решение

**Выбран вариант `formula-v3-coeff`** — изменение коэффициента с 0.6 на 0.4.

Это решение было принято по требованию заказчика, так как даёт более реалистичные значения предела прочности готовой проволоки.
