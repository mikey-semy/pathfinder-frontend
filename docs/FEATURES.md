# PathFinder - Реализованные возможности

## Обзор приложения

PathFinder - это веб-приложение для расчета маршрутов волочения проволоки с полной визуализацией результатов.

**Запуск:** `npm run dev` → http://localhost:3000

---

## ✅ Реализованные функции

### 1. Форма ввода параметров
**Файл:** `src/features/calculation-form/ui/CalculationForm.tsx`

- **React Hook Form + Zod** для валидации
- **11 полей ввода** организованы в 3 секции:
  - Параметры проволоки (тип заготовки, диаметры)
  - Параметры материала (содержание углерода, предел прочности)
  - Параметры процесса (количество переходов, скорость, обжатие)
- **Валидация в реальном времени:**
  - Проверка диапазонов значений
  - Перекрестная валидация (финальный диаметр < начального)
  - Отображение ошибок на уровне полей и формы
- **UX:**
  - Валидация при потере фокуса (`onBlur`)
  - Отключенная кнопка до валидности формы
  - Кнопка "Очистить" для сброса формы

### 2. Отображение результатов (таблицы)
**Файл:** `src/features/results-display/ui/ResultsTable.tsx`

- **Базовые расчеты:**
  - Общее обжатие, среднее обжатие
  - Коэффициент распределения
  - Скорость входа
  - Производительность (кг/ч, т/8ч)

- **Таблица по блокам:**
  - Обжатие, диаметр, скорость
  - Предел прочности (мин/макс/расчетный)
  - Усилие волочения, мощность

- **Дополнительная таблица:**
  - Температура (°C и °F)
  - RPM блока и мотора
  - Полезная мощность, напряжение

- **Итоговые показатели:**
  - Требуемая/доступная мощность
  - Использование мощности (%)
  - Удлинение проволоки
  - Конечный предел прочности

### 3. Графики (Recharts)
**Файл:** `src/features/results-charts/ui/ResultsCharts.tsx`

**4 интерактивных графика:**

1. **Диаметр и скорость по блокам** (Line Chart)
   - Две оси Y для разных единиц измерения
   - Плавная визуализация изменения параметров

2. **Единичное обжатие** (Bar Chart)
   - Процент обжатия на каждом переходе

3. **Усилие и мощность** (Line Chart)
   - Силовые параметры процесса
   - Две оси для кН и кВт

4. **Температура по блокам** (Bar Chart)
   - Нагрев проволоки при волочении

**Возможности:**
- Адаптивный дизайн (ResponsiveContainer)
- Интерактивные подсказки (Tooltip)
- Легенда для каждого графика
- Цветовое кодирование параметров

### 4. Zustand Store
**Файл:** `src/shared/store/useCalculationStore.ts`

**Управление состоянием:**
- Текущий результат расчета
- История последних 10 расчетов
- Автосохранение в localStorage (persist middleware)

**API:**
```typescript
// Сохранить результат
setCurrentResult(result)

// Очистить текущий результат
clearCurrentResult()

// История
addToHistory(result, name?)
loadFromHistory(id)
removeFromHistory(id)
clearHistory()

// Экспорт
exportCurrentResult() // JSON
```

### 5. История расчетов
**Файл:** `src/features/calculation-history/ui/CalculationHistory.tsx`

**Возможности:**
- Отображение последних расчетов
- Краткая информация по каждому расчету:
  - Диаметры (начальный → конечный)
  - Количество переходов
  - Дата и время
- **Действия:**
  - Загрузить расчет из истории
  - Удалить отдельный расчет
  - Очистить всю историю
- Автоматическая прокрутка к результатам при загрузке

## 📝 Использование

1. Заполните форму с параметрами заготовки и процесса
2. Нажмите "Рассчитать маршрут"
3. Просмотрите результаты в таблицах
4. Изучите графики для визуального анализа
5. Предыдущие расчеты сохраняются в истории автоматически

**Приложение готово к использованию!** 🎉
