# PathFinder - Быстрый старт

## 🚀 Запуск приложения

```bash
npm run dev
```

Откройте http://localhost:3000

---

## 📋 Как пользоваться

### 1. Выбор марки стали

В форме расчета сначала выберите марку стали из выпадающего списка:
- **К70, К75, К80, К85** - углеродистые стали
- **65Г, 70Г** - пружинные стали
- **Другая марка** - для ввода пользовательских параметров

При выборе марки автоматически заполнятся:
- Содержание углерода (мин/макс)
- σв заготовки (мин/макс)
- Тип заготовки

### 2. Заполнение формы

**Обязательные поля:**
- Марка стали
- Диаметр заготовки (мм)
- Диаметр готовой проволоки (мм)
- Количество переходов (1-11)
- Скорость волочения (м/с)
- Обжатие в последней волоке (%)

**Автозаполняемые поля** (при выборе марки):
- Тип заготовки
- Содержание углерода мин/макс
- σв заготовки мин/макс

**Опциональные поля:**
- 1 ед. обжатие (%)
- Начать с блока №

### 3. Расчет

Нажмите кнопку **"Рассчитать маршрут"**.

Результаты автоматически появятся ниже формы.

### 4. Просмотр результатов

#### Таблицы результатов:
1. **Базовые расчеты** - общие параметры процесса
2. **Расчет по блокам** - детальные данные для каждого перехода
3. **Дополнительные параметры** - температура, RPM, напряжение
4. **Итоговые показатели** - мощность, удлинение, конечная прочность

#### Графики:
1. **Диаметр и скорость** - изменение по блокам
2. **Обжатие** - процент на каждом переходе
3. **Усилие и мощность** - силовые параметры
4. **Температура** - нагрев проволоки

### 5. Экспорт результатов

Кнопка **"Экспорт в Excel"** над результатами сохранит:
- 4 листа с полными данными
- Все таблицы и параметры
- Файл: `pathfinder_YYYY-MM-DD.xlsx`

### 6. История расчетов

Последние 10 расчетов автоматически сохраняются.

Для загрузки предыдущего расчета:
1. Найдите карточку в разделе "История расчетов"
2. Нажмите кнопку **"Загрузить"**

Для удаления:
- Отдельный расчет - кнопка **"Удалить"**
- Вся история - кнопка **"Очистить историю"**

### 7. Переключение темы

Кнопка в правом верхнем углу:
- ☀️ Светлая тема (по умолчанию)
- 🌙 Темная тема

Выбранная тема сохраняется автоматически.

## 🎯 Примеры использования

### Расчет для К85

1. Выберите марку: **К85 (0.80-0.90% C)**
2. Диаметр заготовки: **4.0 мм**
3. Диаметр готовой: **1.30 мм**
4. Количество переходов: **9**
5. Скорость: **9.0 м/с**
6. Обжатие в последней волоке: **20%**
7. Нажмите **"Рассчитать маршрут"**

### Пользовательская марка

1. Выберите: **Другая марка стали**
2. Введите тип заготовки вручную
3. Заполните содержание углерода (мин/макс)
4. Заполните σв заготовки (мин/макс)
5. Продолжите с диаметрами и параметрами процесса

---

## ⚠️ Важно

- Диаметр готовой проволоки **должен быть меньше** диаметра заготовки
- Максимальное содержание углерода **должно быть ≥** минимального
- Максимальный σв **должен быть ≥** минимального
- Используются только **активные блоки** (пропущенные блоки не отображаются)

## 🐛 Поиск и устранение неполадок

### Ошибки валидации

Если кнопка "Рассчитать" неактивна:
1. Проверьте красные поля с ошибками
2. Прочитайте текст ошибки под полем
3. Исправьте значения

### Ошибки расчета

При ошибке расчета:
1. Откройте консоль браузера (F12)
2. Скопируйте текст ошибки
3. Проверьте входные данные

### История не сохраняется

Убедитесь, что:
- Браузер разрешает localStorage
- Режим инкогнито выключен
